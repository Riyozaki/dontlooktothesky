# Briefs — брифы дней от Kimi

Здесь лежат посценовые брифы новых глав от второго агента (Kimi). Формат: `dXX-brief.md` или `cXX-brief.md`.

Обязательный минимум брифа дня:
- День, файл (`game/dXX.rpy`), бюджет слов из `full-story-plan.md`.
- Функция дня (1 абзац) + список обязательных смысловых узлов.
- Континуитет: какие долги предыдущих глав нужно сыграть, какие hooks посеять.
- Меню дня: сколько, какие выборы, какие переменные (маскировка обязательна).
- Ограничения дня (локации, музыка, новые фоны — с пометкой в трекер, если фона нет).

Писатель исполняет бриф; отступления — только через доску `docs/state/from-arena.md` с согласованием.
