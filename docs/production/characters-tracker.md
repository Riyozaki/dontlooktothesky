# Трекер персонажей и спрайтов — что есть, чего не хватает

**Статус:** рабочий журнал ассетов персонажей. Ведётся параллельно с
`backgrounds-tracker.md`. Цель — видеть, у кого достаточно эмоций/нарядов для написанных сцен,
а кого придётся либо ограничивать по экспрессии, либо дорисовывать.

## Персонажи без спрайтов вообще

- **Наблюдатель / Ревизор** — в `definitions.rpy` определён как говорящий персонаж
  (`r = Character("Ревизор", ...)`), но папки с изображением нет. По `character-bible.md` §58
  он появляется зримо только в линии Валерии как «нейтральный Ревизор» — понадобится
  минимум один визуальный образ, когда дойдём до соответствующих дней (13–20, линия
  Валерии). До этого момента не критично — в C00 он присутствует только как голос без тела
  («Не смотри на небо»).
- **Механик** — есть заготовка персонажа в `definitions.rpy` (`mechanic`), спрайта нет.
  Разовый эпизодический персонаж (велосипед в ремонте), скорее всего можно обойтись без
  спрайта (голос за кадром/безликий) — не блокирует работу.
- **Водитель** — определён в `definitions.rpy`, но по решению автора от 25.07.2026 полностью
  убран как персонаж из базовых маршрутов (см. `master-structure.md`). Спрайт не нужен, пока
  не начнётся разработка Истинного пути (единственное место, где он мог бы вернуться).
- **Собеседники нейтрального маршрута** (учёный-скептик, религиозная фигура гностического
  толка, человек с околосмертным опытом — см. `routes/neutral-plan.md` §7) — имена, внешность
  и спрайты не существуют вообще. Понадобятся к моменту, когда дойдём до нейтральной линии
  (дни 13–20).
- **Представители Пекла помимо Ники/Валерии** — если по сюжету дней 13–20 (линия Валерии или
  N) появятся другие обитатели Пекла, для них тоже ничего не готово.
- **Эпизодические персонажи C00** (кассирша аптеки, охранник бизнес-центра, женщина с котом
  Судьбой, старик из частного сектора, мать с ребёнком, флористка) — все они написаны без
  спрайтов и без тегов персонажа (реплики идут как безличная строка `"..."`, без `Character`).
  Это осознанный и адекватный выбор для одноразовых эпизодических ролей — фиксирую как рабочую
  норму, не как недостаток.

## Технический долг по персонажам

- Дублирование `mirael_*` / `mirael_v3_*` и `valeria_*` / `valeria_v3_*` в файлах — не мешает
  работе (definitions.rpy аккуратно ссылается на актуальные `_v3_*`), но старые версии зря
  занимают место в репозитории. Не трогать без прямого решения автора — возможно, пригодятся
  для сравнения при следующей перерисовке.
- `reference_v2_postponed/` и `reference_valeria_outfits/` — референсные папки, не
  подключённые к `definitions.rpy` напрямую. Держать как материал для художника, не как
  игровые ассеты.

## Правило ведения

Обновлять эту таблицу при каждом появлении нового именованного персонажа в написанной главе.
Если для персонажа не хватает нужной эмоции по ходу сцены — не изобретать несуществующий тег
спрайта, а либо взять ближайший подходящий, либо оставить сцену без смены выражения и
зафиксировать здесь недостающую эмоцию как заявку.
