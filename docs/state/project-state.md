## Что произошло 25.07.2026

Проведена полная содержательная пересборка сюжета (не техническая уборка — именно сюжет):

1. Зафиксирован скрытый мотив истории («в чём смысл моей жизни») и то, как три маршрута
   отвечают на него через ценности: любовь (Мираэль), страсть/риск (Валерия), знание
   (нейтральный).
2. Срок до утра дня 21 закреплён как обязательный факт мира, а не механика одной ветки:
   если статус Александра не закрыт легитимно, аномалия закрывается сама, обычной смертью.
3. Введён «закон трёх пиков»: в каждой линии есть плохой исход, честный «нижний хороший» и
   пиковый исход, где герой отпускает потребность в гарантии полностью — в двух линиях это
   означает принятие собственной смертности без страха, в третьей — единственный способ её
   по-настоящему избежать.
4. Решено убрать все земные бюрократические инстанции (кабинеты, турникеты, коридоры
   администрации) до дня 13 — их заменяют короткие пороговые переходы; полноценные Верх и
   Пекло как локации доступны только с дня 13.
5. Переписаны как основа для будущей прозы: `docs/story/master-structure.md`,
   `docs/story/story-structure.md`, `docs/story/routes/mirael-plan.md`,
   `docs/story/routes/valeria-plan.md`, `docs/story/routes/neutral-plan.md`.
6. Удалены поглощённые новыми документами файлы (полезное содержимое учтено, остальное — в
   истории git): `rebuild-agenda.md`, `legacy-routes-review.md`, `old-routes-full-audit.md`,
   `story-map.md`, `common-week-plan.md`, `routes/valeria-brief.md`, `routes/neutral-brief.md`,
   `routes/valeria-endings-plan.md`, `routes/mirael-additions.md`, `routes/v01–v08-plan.md`,
   старые посценовые карты `c04-plan*.md`, `c05-plan*.md`, `c06-plan.md`, `d08-plan.md`,
   `d10-plan.md`.

## Как читать этот документ

Раздел «Что фактически на диске» — проверенное состояние `game/*.rpy`. Раздел «Актуальный
сюжетный план» — новая логика из `master-structure.md`, которая **пока не воплощена в тексте**
для M и V (они написаны по старой логике финалов) и вообще не воплощена для N (только план).
Расхождение между текстом и планом сейчас — ожидаемая рабочая точка, а не ошибка.

### C00 — детали переписывания (25.07.2026)

Полностью новый текст, без единой строки из прежней версии. Одиннадцать сцен, линейная проза
с тремя игровыми выборами (см. ниже). Прошёл полный цикл: черновик → тройное ревью (читатель /
писатель / редактор) → редакторский проход по `HARD-BLOCKERS.md` → `style_guard.py` чист
(0 блокеров) → `validate_renpy_static.py` и `audit_text_transfer.py` чисты.

При редакторском проходе вырезаны два эпизода, добавленных ранее исключительно ради объёма
без функции в сюжете или характере (случайное столкновение с юристом в коридоре, диалог
грузчиков о футболе) — итоговый объём (с учётом добавленных позже выборов) — 9446 видимых слов
по всем ветвям, не подогнан под верхнюю границу диапазона искусственным заполнением.

**Игровые выборы (добавлены после первичного ревью, по прямому решению автора — без выборов
это не новелла):** три развилки, каждая с реальными последствиями в тексте той же главы и
влиянием на будущий resolver через новые переменные-предвестники (`alex_care`, `alex_edge`,
`alex_curiosity`, `alex_avoidance` — см. `master-structure.md` §11):

1. Звонок матери утром — ответить или сбросить.
2. Странность с расходящимся временем на чеке в аптеке — спросить или пройти мимо.
3. Дополнительный вечерний заказ с повышенным тарифом перед аварией — взять ради денег
   (объясняет повышенную физическую усталость перед аварией) или отказаться.

Оба ответвления полностью прописаны текстом (не заглушки), последующие сцены (разговор с
Леной про звонок, состояние тела на дороге к аварии) корректно ветвятся по выбранному пути.

`scripts/test_mirael_endings.py` обновлён: раньше он ожидал ровно один `alex_responsibility +=
1` внутри `c00.rpy` (из старого игрового выбора «сказать, что проспал»/«назвать время выхода»
прежней версии главы). Новый C00 использует другую систему переменных (предвестники ценностей,
а не `alex_responsibility` напрямую), поэтому файл по-прежнему исключён из проверяемого списка
этого теста — старый resolver `mirael_logic.py` относится к прежней логике финалов и будет
переосмыслен вместе с переписыванием маршрута Мираэль (см. `routes/mirael-plan.md`).

## Актуальный сюжетный план

Полностью в [`master-structure.md`](../story/master-structure.md) и трёх файлах
`routes/*-plan.md`. Кратко: три маршрута отвечают на скрытый вопрос «в чём смысл жизни» через
любовь/страсть/знание; в каждом — плохой, нижний хороший и пиковый финал; срок — обязательный
фон всей игры; Истинный путь открывается только тремя пиковыми финалами и намеренно не
проектируется раньше срока.
