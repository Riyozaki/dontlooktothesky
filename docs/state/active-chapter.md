# Активная глава

**Статус:** `C00`–`C05` переписаны заново и завершены (25–27.07.2026, см.
`docs/state/project-state.md`). Следующая глава, требующая новой прозы — `C06`.

## Что дальше по документам

По `docs/story/full-story-plan.md` следующая глава — `C06` (день 7: собрать три направления
недели в конкретный вопрос и в выбор занятия дня 8, без объявления финального маршрута.
Содержание: Александр впервые формулирует вслух главный вопрос будущего N-маршрута — «а нужен
ли душе владелец вообще» — как практический вывод из двух моделей, которые обе заканчиваются
пустым полем; Ника, Валерия, Мираэль и Лена присутствуют фоном обычного дня, никто не решает за
Александра; вечер на кухне с тремя предметами на столе как символом трёх возможностей, тихий
разговор без пафоса; финал дня — выбор занятия дня 8 (`priority_1 = mir / val / neut`), поданный
не как «кого я люблю» или «чей я», а просто «чем я займусь завтра», без объяснения игроку, что
это решает будущую траекторию).

Посценовая карта для неё пока не написана — старая версия C06 признана архивом наравне с
C07–C09.

Активировать конкретную главу и бюджет сцен для `chapter_gate.py` можно после того, как будет
создана новая посценовая карта C06 в соответствии с `master-structure.md` и `full-story-plan.md`.

## Важно для C06 конкретно

- C06 — последняя глава общей недели и завершает цепочку `c00→...→c06` перед днём 8. После неё
  по плану идут три версии дня 8 (`d08_m.rpy`/`d08_v.rpy`/`d08_n.rpy`), которые ещё не написаны.
- Финальный выбор дня записывается в `priority_1`, но по прямому правилу проекта — без
  объяснения игроку, что это решает будущую траекторию (см. `master-structure.md` §6, §11).
- Перед перезаписью файла `game/c06.rpy` обязательно проверить
  `git show HEAD:game/c06.rpy | grep -n "alex_responsibility\|mirael_autonomy\|mirael_closeness"`
  — если старая версия содержит эти переменные, повторить процедуру уменьшения счётчиков в
  `scripts/test_mirael_endings.py` (см. `docs/production/process-journal.md`, урок №5).
- Автор прямо разрешил не подгонять сюжет под наличие/отсутствие фонов — писать свободно, нужные
  фоны просто фиксировать в `docs/production/backgrounds-tracker.md` для будущей пакетной
  генерации (решение от 27.07.2026).
