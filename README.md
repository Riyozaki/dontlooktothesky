# Don't Look to the Sky

Некоммерческая визуальная новелла на Ren'Py. Проект в разработке.

## Текущий статус (обновлено 25 июля 2026 — после пересборки сюжета)

25 июля 2026 сюжет прошёл полную содержательную пересборку: зафиксирован скрытый мотив
истории, обязательный срок как факт мира и «закон трёх пиков» для всех финалов. Подробности —
[состояние проекта](docs/state/project-state.md) и [мастер-структура](docs/story/master-structure.md).

Фактическое состояние текста в `game/*.rpy` на этот момент:

- `C00–C03` — новая романная редакция общей недели, написана, проходит стилевые проверки;
- `C04–C09` — старая реализация, признана черновиком под снос; будет переписана заново по
  новому сюжетному решению (иные измерения вместо земных инстанций, см.
  `docs/story/master-structure.md` §5–§6);
- маршрут Мираэль `M01–M07` и финалы `E01/E02` — написаны по **прежней** логике финалов;
  требуют переписывания под новый закон трёх пиков (обязательная смерть в E01, переосмысленный
  E02) — см. `docs/story/routes/mirael-plan.md`;
- маршрут Валерии `V01–V08` и финалы `E03–E05` — написаны по **прежней** логике; требуют
  переписывания под новый закон трёх пиков (настоящая физическая ставка в итоговой проверке) —
  см. `docs/story/routes/valeria-plan.md`;
- нейтральный маршрут — только план, `docs/story/routes/neutral-plan.md`, полностью пересобран
  под новую механику (единственная линия, где смерть можно по-настоящему обойти);
- Истинный путь — сознательно не проектируется до завершения трёх пиковых финалов.

Диспетчер `game/script.rpy` пока собран по старой модели (один выбор маршрута после C09) и
потребует пересборки под архитектуру 21 дня.

## Канонический текст

Художественный источник находится только в `game/*.rpy`.

```text
game/
├── c00.rpy–c09.rpy
├── m01.rpy–m07.rpy
├── v01.rpy–v08.rpy
├── e01.rpy–e05.rpy
├── definitions.rpy
├── script.rpy
└── UI/config files
```

`docs/manuscript/*.md` — автоматически создаваемые зеркала для чтения. Они не редактируются
вручную.

## Документация

```text
docs/
├── bible/       — персонажи и космология
├── state/       — текущий этап
├── story/       — канон мира, маршруты и постановка
├── manuscript/  — зеркала активной прозы и несколько актуальных аудитов
└── licenses/    — лицензии ассетов
```

Справочные документы прежней (до пересборки 25.07.2026) реализации линии Мираэль — доступны
для чтения, но не отражают новую логику финалов:

- [детальный итоговый проход](docs/manuscript/mirael-route-full-read.md)
- [автоматическая логика концовок](docs/manuscript/mirael-ending-logic-report.md)

## Ассеты

- `images/` — фоны, персонажи и референсы;
- `game/audio/music/`, `game/audio/sfx/` — подключённые музыка и звуки, определены в
  `definitions.rpy`;
- `game/ui/` — используемые интерфейсные ассеты;
- `images/ui_source/` — исходные UI-листы, сохранены для дальнейшей нарезки.

Ren'Py SDK и собранные файлы игры в репозитории не хранятся.
